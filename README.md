# 薩魔海岸砲撃戦

ひとりで海岸警備を任された薩魔藩士が、夕暮れの浜から瑛国の戦列艦を狙う3D砲撃ゲームです。ブラウザだけで遊べます。

## 遊び方

- 制限時間のうちに瑛兵を全員、倒すか海へ落とせば勝ち。時間が尽きると瑛艦の反撃が始まります。
- 得物は弓矢・火縄銃・大砲の3つ。攻撃力と弾数は反比例（攻撃力 × 弾数 ＝ 600）。
- 船体（船首・中央・船尾）、帆柱（上檣・下檣）、帆、砲門をそれぞれ壊せます。
- 難易度は 易・並・難 の3段階。難 HARD を制すると「薩魔ホグワーツモード」（水・火・落雷の魔法）が解放されます。

| 操作 | マウス | スマホ | キー |
|---|---|---|---|
| 狙う | 動かす | 指でなぞる | |
| 撃つ | クリック | 指を離す | スペース |
| 持ち替え | 下の札 | 下の札 | 1・2・3 |
| 遠眼鏡 | 右クリック | 下の札 | Z |

## 動かし方

`index.html` をブラウザで開くだけで動きます。3D表示に [three.js](https://threejs.org/)（MIT License）を CDN から読み込んでいます。

※史実とは異なる創作の物語です。
